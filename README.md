# نظام المرتبات الشامل - Payroll System

نظام ويب متكامل لإدارة الرواتب والموظفين باللغة العربية (RTL)، يدعم ثلاثة أنواع للتعويض:
موظف براتب شهري (مرتب ثابت)، جهة حكومية، وعمالة يومية/بالساعة.

## المزايا الرئيسية

- **إدارة الموظفين**: إضافة وتعديل وحذف، بيانات شخصية، رواتب أساسية وبدلات، أنواع دفع متعددة.
- **إدارة الأقسام** بتمكينها أو تعطيلها.
- **الحضور والانصراف**: أيام الحضور والغياب والتأخير لكل شهر.
- **الإضافي والعمولات والخصومات** لكل موظف شهرياً.
- **السلف**: سلف متعددة الأقساط مع متابعة تلقائية للأقساط والمتبقي عند اعتماد المرتبات.
- **الإجازات**: طلبات إجازات مدفوعة/بدون أجر مع اعتمادها.
- **الرواتب**: حساب شامل (أساسي، بدلات، إضافي، عمولات، سلف، غياب، تأخير، تأمينات، ضرائب) مع
  **قسيمة راتب PDF** جاهزة للطباعة، وتصدير Excel.
- **حوافز/خصومات جماعية** تُطبق على الموظفين دفعة واحدة.
- **العقود** مع تنبيهات للعقود المنتهية قريباً.
- **التقارير**: تقارير الأقسام، المقارنة بين أشهر، التقرير السنوي، سجل التوقيعات، سجل التدقيق.
- **المستخدمون**: صلاحيات (مدير/مستخدم) مع تفعيل/تعطيل الحسابات.
- **الأمان**: حماية CSRF على جميع عمليات تعديل البيانات، تشفير كلمات المرور، تقييد محاولات الدخول، سجل تدقيق كامل، وإلزام المدير بتغيير كلمة المرور الافتراضية عند أول تسجيل دخول.
- **النسخ الاحتياطي**: نسخة احتياطية تلقائية مرة كل شهر + إنشاء/استعادة/تحميل/حذف نسخ يدوي من صفحة الإعدادات.
- **الوضع الليلي** وتصميم متجاوب بالكامل.

## المتطلبات

- Python 3.9+
- المكتبات في `requirements.txt`:
  `Flask`, `Werkzeug`, `openpyxl`, `reportlab`, `arabic-reshaper`, `python-bidi`, `Pillow`

## التشغيل والتثبيت

```bash
# 1) تثبيت المتطلبات
pip install -r requirements.txt

# 2) تشغيل التطبيق
python app.py
```

ثم افتح المتصفح على: `http://localhost:5000`

أو على Windows شغّل الملف مباشرة:

```
run.bat
```

> سيتم إنشاء قاعدة البيانات `payroll.db` تلقائياً عند أول تشغيل.

## نسخة تشغيل جاهزة (Windows EXE)

يمكن تشغيل النظام كملف واحد **بدون الحاجة إلى تثبيت Python** و**بدون نافذة CMD**:

1. انسخ ملف `نظام_المرتبات.exe` إلى أي مجلد تريده.
2. انقر عليه نقراً مزدوجاً — سيبدأ الخادم في الخلفية (بصمت) ويفتح المتصفح تلقائياً على صفحة تسجيل الدخول.
3. عند أول تشغيل يُنشئ الـ exe قاعدة بيانات `payroll.db` (بالمستخدمين الأربعة) **بجواره هو نفسه**، وتُحفظ كل بيانات العمل هناك وتستمر بين التشغيلات.

> **لكي يبقى الخادم قيد العمل، أبقِ الـ exe مفتوحاً** (برمجياً يمكن إيقافه من إدارة المهام). قاعدة البيانات والنسخ الاحتياطية والمفتاح السري موجودة جميعاً في نفس مجلد الـ exe.
>
> **لبناء الـ exe بنفسك** من الشيفرة المصدرية (نافذة واحدة بدون CMD + أيقونة):
> ```bash
> pip install pyinstaller
> python -m PyInstaller --noconfirm --clean payroll.spec
> ```
> الناتج في مجلد `dist/`.

## بيانات الدخول الافتراضية

| المستخدم | كلمة المرور | الاسم الكامل | الدور |
|----------|-------------|--------------|-------|
| admin     | admin123    | مدير النظام  | مدير (كل الصلاحيات) |
| supervisor| super123    | محمد المشرف  | مشرف |
| user      | user123     | سارة المستخدمة | مستخدم |
| viewer    | viewer123   | خالد المشاهد | مشاهد (عرض فقط) |

> ⚠️ **إلزام أمني:** سيُطلب من **المدير (admin)** تغيير كلمة المرور الافتراضية فور أول تسجيل دخول، ولن يُسمح له بالمتابعة قبل ذلك. هذه خطوة إلزامية لحماية البيانات.
>
> **الصلاحيات:** المدير يملك كل الصلاحيات، المشرف يدير الموظفين والمرتبات والسلف والعقود والحوافز، المستخدم يضيف الحضور/الإضافي/العمولات/الخصومات/الإجازات، والمشاهد يقرأ فقط دون تعديل.

## النسخ الاحتياطي والاستعادة

- **تلقائياً:** يُنشئ النظام نسخة احتياطية من قاعدة البيانات **مرة كل شهر** تلقائياً.
- **يدوياً:** من صفحة **الإعدادات → النسخ الاحتياطي لقاعدة البيانات** يمكنك:
  - إنشاء نسخة احتياطية فوراً.
  - استعادة نسخة سابقة (يتم إلغاء الجلسة بعد الاستعادة).
  - تحميل نسخة للاحتفاظ بها خارجياً.
  - حذف نسخة قديمة.

تُحفظ النسخ في مجلد `backups/` داخل المشروع (مستثنى من الرفع على الجيت هاب).

## تقنية

- **الواجهة**: HTML + CSS + JavaScript (بدون إطار عمل أمامي)
- **الخلفية**: Flask (Python)
- **قاعدة البيانات**: SQLite
- **التقارير**: openpyxl (Excel) + reportlab (PDF)
- **الترقيم**: Babel notation عبر arabic_reshaper و python-bidi لطباعة عربية صحيحة في PDF

## ملاحظات النشر

- يتم تخزين مفتاح الجلسة في ملف `.secret_key` (لا يُرفع للجيت هاب).
- قاعدة البيانات `payroll.db` لا تُرفع للجيت هاب (تُنشأ محلياً).
- **HTTPS:** عند النشر على سيرفر خارجي يستخدم HTTPS، ابدأ التطبيق مع متغير البيئة `PAYROLL_HTTPS=1`
  لتفعيل الكوكيز الآمنة (Secure cookies):
  ```bash
  # Windows (PowerShell)
  $env:PAYROLL_HTTPS="1"; python app.py
  # Linux/macOS
  PAYROLL_HTTPS=1 python app.py
  ```
